# Concepts

Memoripy v4 is built around six concepts:

1. **Evidence** is the source material that was observed.
2. **Admission** decides whether a derived candidate may become memory.
3. **Memory records** represent the current view of a typed slot.
4. **Versions** preserve how that slot changed over valid time.
5. **Retrieval receipts** explain why a memory was selected.
6. **Audits and contracts** measure whether the store remains trustworthy.

Read [v4 architecture](./v4-architecture.md) for the complete model.
